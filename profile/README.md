## About

GitHub organization for the MCA department at NIT Warangal. We maintain shared academic resources, a placement portal, and collaborative tools for students.

**Admins:** [@Sagargupta16](https://github.com/Sagargupta16), [@sachin-gupta99](https://github.com/sachin-gupta99)

## Repositories

| Repo | Description | Stack |
|------|-------------|-------|
| [**placemento**](https://github.com/MCA-NITW/placemento) | Placement portal -- company tracking, student profiles, interview experiences | React 19, Express 5, TypeScript, MongoDB, Vite |
| [**mca_nitw**](https://github.com/MCA-NITW/mca_nitw) | Official MCA course website | React, Express, MongoDB |
| [**leetcode_among_us**](https://github.com/MCA-NITW/leetcode_among_us) | Competitive coding tracker -- LeetCode stats and leaderboard | TypeScript, React, Vite, pnpm |
| [**Academic**](https://github.com/MCA-NITW/Academic) | Semester-wise notes, assignments, and study material (Sem 1-4) | Markdown, PDFs |

## Join the org

Current MCA-NITW students and alumni can request access:

1. [Open a Join Request](https://github.com/MCA-NITW/.github/issues/new?assignees=&labels=join-request&template=join-request.yml&title=%5BJoin+Request%5D+%40your-username)
2. Fill in your GitHub username
3. Automated invitation is sent within minutes

---

## Contributing

All repos use:
- **Renovate** for automated dependency updates (one grouped PR in the first week of each month, auto-merged when CI is green; security fixes land immediately)
- **Reusable CI workflows** from this `.github` repo (build, lint, security scan)
- **Conventional Commits** (`feat:`, `fix:`, `chore:`, `docs:`)

See [CONTRIBUTING.md](https://github.com/MCA-NITW/.github/blob/main/.github/CONTRIBUTING.md) for full guidelines.
